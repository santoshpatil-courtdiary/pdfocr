Any rotation you set above is applied before OCR, so rotate sideways or upside down scans first for correct recognition. The OCR engine and the Marathi, Hindi and English language data are built into this app, so OCR works without an internet connection. Marathi OCR is slower than English, and a 200 dpi page typically takes several seconds.
Reduce PDF size:
This lowers the resolution and quality of the images inside the pages. Text, OCR text layers, page order and rotation are kept. It works best on scanned and photographed pages. A PDF that is mostly text, or whose scans are already small, may not shrink much, and in that case no file is saved. Always check the reduced file before replacing the original. To reduce a scan that you have just run through OCR, open the saved _OCR.pdf and reduce that one.
